# agrostory
=======
Brocolli is a modern full-stack e-commerce web application that enables users to browse, purchase, and have fresh agricultural products delivered directly to their doorstep. The platform is built to connect farmers and consumers seamlessly, improving accessibility to fresh farm produce through a digital marketplace.

🚀 Key Features
🛒 Product browsing with categories (grains, legumes, vegetables, etc.)
🔍 Search and filter functionality for easy product discovery
❤️ Wishlist and cart management system
📦 Stock availability indicators (In Stock / Sold Out)
👤 User-friendly and responsive UI for all devices
💳 Secure payment integration for seamless checkout (in development)
🚚 Order placement and delivery tracking system (in development)

🧠 Tech Stack
Frontend: HTML, CSS Tailwind, JavaScript
Backend: Express
Database: MongoDB / MySQL
Payment Integration: Paystack
Version Control: Git & GitHub

🎯 Purpose
The goal of Brocolli is to digitize agricultural trade, reduce middlemen, and make fresh farm produce easily accessible while supporting farmers with a direct-to-consumer platform.
